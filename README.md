## Temática elegida

Sitio web de turismo con Boostrap

## Descripción

Sitio web informativo sobre la ciudad de Estrasburgo que incluye
Inicio
Flora-y-fauna
Que-visitar
Contacto

Componentes de Bootstrap utilizados

- Navbar responsivo, con direccionado a la página que corresponda
- Carousel, se modificó el carousel caption con d-flex para centrar el texto al centro
- Cards, para mostrar algunos de los lugares de la ciudad
- Buttons, para redirigir a la página que visitar,
- Footer, con d-flex para centrarlo
- Formulario de contacto
